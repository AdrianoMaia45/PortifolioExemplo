# Portfólio Exemplo
## 📌 Sobre o Projeto

Este projeto consiste em um modelo de portfólio desenvolvido a partir de um design no Figma.

O foco principal foi transformar o layout em uma interface fiel ao protótipo, utilizando apenas HTML e CSS, sem JavaScript.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Figma

---

## 🎯 Objetivos do Projeto

- Praticar interpretação de layouts no Figma
- Desenvolver interfaces responsivas
- Melhorar estruturação semântica
- Trabalhar estilização avançada com CSS

---

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- 📱 Smartphones
- 💻 Desktop
- 📲 Tablets
